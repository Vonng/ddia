- **译者**：[冯若航 / Vonng](https://vonng.com) 与 DDIA 中文翻译贡献者

> 不懂数据库的全栈工程师不是好架构师。
>
> —— 冯若航 / Vonng

第一版沿着可靠性、可伸缩性与可维护性展开，系统讲解数据模型、存储、复制、分区、事务、一致性，以及批处理和流处理。许多文章、课程与讨论仍引用这一版的章节和图号，因此本站完整保留其中文译文与稳定链接。

在线版本提供章节树导航、稳定图号与交叉引用、全文搜索、顺序阅读、整书打印以及适合工具读取的 Markdown / `llms.txt` 输出。阅读第二版时，也可以随时通过顶部版本菜单回到对应语言的第一版首页。
